Task-oriented walkthroughs for common Orchard setups. Each guide presents a
real-world scenario, shows the HCL that expresses it, and explains the design
choices.

- [Seeding a demo environment](demo-seeding/) — rich, realistic data for product
  demos and sales pitches.
- [Manual UAT testing](uat-testing/) — reproducible test cases for QA and
  stakeholders.
- [Local development environments](local-dev/) — let engineers spin up a working
  database with one command.
- [Integration testing](integration-testing/) — shared setup for automated test
  suites.
- [Composing components](composing-components/) — patterns for breaking scenarios
  down into reusable parts.

These assume you've read the [Getting started](../getting-started/) section and
understand [concepts](../concepts/).
