Exhaustive reference for Orchard's CLI, HCL schema, expression language, and
function library.

- [CLI](cli/) — `init`, `run`, `plan`, `list`, `teardown`, `docs`, `functions`; flags and environment variables.
- [HCL schema](hcl-schema/) — every top-level block, attribute, and nested block.
- [Expressions](expressions/) — reference namespaces, type expressions, operators.
- [Functions](functions/) — all available functions with signatures, descriptions,
  and examples. Auto-generated from the function registry.

For per-provider reference (config attributes, action types, outputs), see the
[providers section](../providers/).
